## 📖 About

**The Nutrition Almanac** is a modern nutrition reference and calorie tracking web application designed to help users explore nutritional information, compare foods, and monitor their daily nutrition.

The application combines an extensive food database with Nutrition Facts labels, a nutrient encyclopedia, food comparison tools, health calculators, and a daily tracker, making nutrition information simple and accessible.

---

# ✨ Features

- 🥗 **561+ foods** covering Indian and international cuisine
- 📖 **Nutrition Encyclopedia** with **27 essential nutrients**
- 🧾 Nutrition Facts style labels for every food
- 📊 Daily calorie & macronutrient tracker
- ❤️ Favourite foods
- 🔍 Instant food search
- ↕ Sort foods by calories, protein, carbs, fat, or name
- ⚖ Side-by-side food comparison
- 🌙 Light & Dark mode
- 🧮 BMI Calculator
- 🔥 BMR Calculator
- 🎯 TDEE Calculator
- 💾 Local storage support

# 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/vaibhav20060110/nutrition-almanac.git
```

Open the project folder:

```bash
cd nutrition-almanac
```

Open **index.html** in your browser.

No build tools or installation are required.
